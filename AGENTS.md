# Working on YUNS

- Follow `.editorconfig` and `.prettierrc.json`: two spaces, readable line breaks, and separate blocks.
- Keep application JavaScript in `src/js/` and styles in `src/css/`.
- Keep interface text in English and use Arial for the interface.
- Preserve the existing appearance and interactions when making maintenance changes.
- Do not format or edit the third-party files in `vendor/`.
- Keep personal documents out of the README and top-level file list.
- Run `npm run format:check` and `npm run check` before publishing changes.
- Use simple commit messages and preserve Git history.
